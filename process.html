AI-Augmented Development

A human-directed development process that uses LLMs for analysis and implementation while keeping requirements, scope, testing, and final decisions under human control.

The Process

My AI-assisted development process evolved through practical use rather than through an attempt to automate software development wholesale.

For independent work, I commonly use two distinct AI roles. A conversational LLM handles the analytical work; GitHub Copilot handles the implementation work inside the development environment.

Conversational LLM: Analysis and Specification

A conversational LLM is used for:

  • Problem analysis
  • Brainstorming
  • Requirements clarification
  • Workflow design
  • Specification writing
  • Adversarial review
  • Identifying ambiguity before implementation

GitHub Copilot: Codebase-Aware Implementation

GitHub Copilot is then used within the development environment for:

  • Codebase-aware implementation
  • Modification of existing features
  • Bug resolution
  • Test creation
  • Code inspection
  • Focused refactoring

How I Work

My implementation prompts usually begin in deliberately ordinary language: “Let's add this feature…” or “Let's resolve an issue where…” I provide as much relevant background as possible while keeping the requested change narrow and finite.

The AI may propose an implementation, but I determine whether the approach fits the existing application, whether it introduces unintended complexity, whether tests are sufficient, and whether the resulting workflow actually works in practice.

When an implementation technically succeeds but creates a bad user experience, I revise the requirement rather than treating generated code as the final authority.

I use AI tools aggressively, but not unquestioningly. AI has allowed me to attempt projects and technical problems I would not previously have known how to approach. It has not removed the need to understand what the software is doing, recognize when an approach is wrong, test the result, or decide whether a feature should exist in the first place.

The goal is not autonomous development. The goal is increased engineering leverage.
