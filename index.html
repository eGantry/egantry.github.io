About

I am a senior software developer with approximately twenty years of professional Java experience. My professional background includes enterprise application development and maintenance using technologies including Java, JavaScript, Ajax, PrimeFaces, Vaadin, Oracle, JBoss, JasperReports, Apache Shiro, and Selenium.

In my current professional work, I support an established enterprise application and develop automated Selenium testing. I also use GitHub Copilot as part of a structured development process for feature work, issue resolution, application maintenance, and test automation.

My independent QuizLabs projects provide a complementary environment for experimentation with application design, specialized problem-solving tools, automated testing, and AI-assisted development techniques. Outside software development, I also have experience in music and visual art — interests that increasingly overlap with my technical work through AI-assisted visual storytelling and multimedia projects.
